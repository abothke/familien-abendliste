# Familien-Abendliste

Ein kleiner Generator für eine islamische Familien-Abendliste zum Ausdrucken.

- Familienname und Abendpunkte selbst eintragen (bis zu 8, „IMMER“-Punkte markierbar)
- Weg mit 30 bis 80 Kreisen: jeder geschaffte Punkt am Abend = ein Kreis ausmalen, keine festen Wochentage
- Belohnung und aktuelle Dua optional vorausfüllen
- Download als PDF (A4 quer) oder Bild, oder direkt drucken
- **Gute Tat nachschauen:** gezogene Zahl (1–50) eingeben und die kindgerechte gute Tat sehen; die zuletzt gezogene Zahl wird gemerkt
- **Zahlenkärtchen:** alle 50 Zahlen als Quadrate zum Ausschneiden (A4 hoch)

Alle Eingaben bleiben nur im eigenen Browser gespeichert.

**Live:** https://abothke.github.io/familien-abendliste/
